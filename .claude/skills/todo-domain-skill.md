## 4. Reusable Skills

Skills represent **reusable domain intelligence** that can be used across
multiple phases and agents.

---

### 4.1 Todo Domain Skill

**Skill Name**
`todo-domain-skill`

**Purpose**
Encapsulates all Todo business logic.

**Capabilities**
- Task lifecycle management
- Completion status handling
- Priority levels (high / medium / low)
- Tags and categories
- Recurring tasks
- Due dates and reminders

**Usage**
Used from Phase I through Phase V.
